• Transport Layer (TCP / UDP): Learn how TCP guarantees reliable, ordered packet delivery via the 3-way handshake, and when to choose fast, connectionless UDP.
• Application Layer (HTTP/1.1, HTTP/2, WebSockets): Understand request/response headers, status codes, keep-alive connections, and multiplexing.
• DNS & Resolution: Learn how domain names map to IP addresses, what Time-to-Live (TTL) caching means, and why DNS lookup delays happen.
• TLS & Security: Learn how a TLS handshake works, how symmetric/asymmetric encryption protects payloads, and what Mutual TLS (mTLS) does.
• Ports, Sockets, and NAT: Understand how your OS routes incoming packets to a specific process (e.g., Node.js on port 3000 or Postgres on 5432) and how Network Address Translation works.
• Reverse Proxies & Load Balancers: Study how tools like Nginx or cloud load balancers handle L4 vs. L7 traffic, termination of SSL, and proxying requests.
